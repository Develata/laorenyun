# 产品与语义

Owner：本文件拥有目标用户、产品定位与证据层级。范围以 [01](01-scope-and-acceptance.md) 为准。

老人云是 AI 引导的口述史和持续生长的自传工具，主要服务约 60–80 岁、可自然说话、能操作基础网页的人。Web-only、单家庭本地单用户；家庭成员可代述，但说话者身份不能混淆。课程优先证明 AI 采访、隔离编排、结构化记忆、可靠语音与可追溯生成。

## 核心流程

原始音频 → 原始 ASR → 用户确认的文字修订 → 结构化时间记忆图 → 第一人称自传。

- 原件是历史材料，删除草稿、重录、重试、清会话不等于删除原件。
- 用户确认文字是该次发言的权威文字；它不是对客观历史真实性的保证。不同证言可以矛盾。
- 记忆图记录有出处的主张、确认状态、推断与矛盾。自传是可重建的派生内容。
- 采访者温和、专业、好奇，以开放问题听取叙事；不诊断心理，不扮演情感伴侣，不制造共同回忆。

## 体验

没有 onboarding 表单。首页只有明显的“开始讲我的故事”，随后自然询问出生地，再询问大致年代；允许“不记得”、跳过、结束、键盘输入。介绍一句腾讯云处理语音的说明并可展开，不要求老人理解模型、工作区或 token。

两处主要空间：“讲故事”和“人生记忆河流”。未来可用成熟 Web wrapper 包装，但不引入原生平台代码。视觉清楚、平静、温暖、字大；不使用医疗机构式或刻板“老年模式”审美。
