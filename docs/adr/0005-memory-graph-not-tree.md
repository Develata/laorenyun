# ADR-0005：时序属性图而非人生树

状态：接受为实现设计；运行验证另列。日期：2026-09-15。Owner：laorenyun。

## 决策

用SQLite关系表表达typed temporal property graph，事件有六要素、key_sentence、时间精度/确定性及字段出处，允许跨时期/人物交叉链接。无时间锚点保持漂流，后续同ID新修订锚定。河流仅投影。

## 替代、代价与失败边界

树不能表达同一人/事件横向关联；完整本体和专用图数据库超出需求。节点间四种最小edge，其余人物关联、来源与Conflict用专表，避免同一事实重复两套关系。日期推断不能转成stated。
