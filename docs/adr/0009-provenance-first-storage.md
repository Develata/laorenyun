# ADR-0009：证据优先与不可变修订

状态：接受为实现设计；运行验证另列。日期：2026-09-15。Owner：laorenyun。

## 决策

原始录音、raw ASR、用户校订是独立保留层，结构记忆为事实领域层，自传为可再生成上层。每个重要生成段绑定节点版本→文字段版本→实际音频范围，缺少精细对齐时显式降级。Speaker快照由用户选择，绝不靠自动推断改变。

## 替代、代价与失败边界

只存聊天/最终文章会丢失历史依据；全文覆盖更新不能审计。采用追加修订+CAS和操作去重，原件文件journal先持久再ack。输入纠错不自动创建历史Conflict；新的确认主张与旧主张矛盾才存Conflict，不默认裁决。

浏览器未上传字节无法宣称Host已保存；已接收partial可恢复但未必可解码。用户删除草稿不等于删除原件；明确删除原件需独立未来设计。
