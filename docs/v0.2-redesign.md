# v0.2 体验重构：设计与验收边界

状态：NOT YET — 复杂稀疏语料的自然自传仍未稳定通过事实审校；未发布；v0.1.0 tag 与历史证据不改。Phase2 R2/R3 实体硬件门禁独立 pending。

## 已查证的平台边界

固定 DSH 0d1f500。`ui-sidebar` 的 `sidebar.brand.mark/name` 可以替换品牌；`sidebar.panellist` 与 `main` 对接主要页面。`ui-layout` 提供折叠导航，不替换整个 shell。`ui-sidebar-right` 的注册 tab 是采访时的辅助预览，不承载长河主视图。`ui-settings-general` 拥有设置壳，`ui-settings-models` 拥有模型设置；v0.1 profile 同时禁用了两者。恢复设置不等于授予模型工具权限。minimal agent preset 不是主题，不采用。

Workspace 注册表以稳定 ID 为身份，同时要求成员账本与 session header.cwd 匹配。人物档案必须使用此真实成员关系；Session 是一次采访，不是一个人生。不得仅按当前浏览器选择来决定异步任务的归属。

## 交互研究（2026-09-16）

- [Histography](https://www.histography.io/)：总览先于细节，底部时间窗控制范围，密度而非所有文字同时呈现。借鉴年代导航/密度，避免照搬历史事件点阵。
- [TimelineJS 原始文档](https://timeline.knightlab.com/docs/index.html)：事件具有独立叙事内容，时间轴保持方向感。老人云采用独立记忆详情，避免概览下无限堆叠详情。
- [Pudding 响应式实践](https://pudding.cool/process/responsive-scrollytelling/)及[实现方法](https://pudding.cool/process/how-to-implement-scrollytelling/)：正常滚动；移动端需重新组织内容，交互不能依靠 hover；布局与绘图分离。无需为长河引入滚动劫持框架。
- [CMU / Clemente The 21st Hour](https://hcii.cmu.edu/mhci/capstone/2021/clemente-museum/design.html)：人生总览引导进入关键时刻的深入故事。借鉴叙事层级，不复制资产或虚拟世界。

## 信息架构

主要入口：讲故事 / 人生长河 / 我的自传 / 设置。品牌“老人云 · 留下讲述，慢慢成书”。长河占据主要画布；详情为二级页面；列表为显式无障碍模式。表达画像、自传阅读、生成和导出归“我的自传”。

长河沿纵向时间前进、横向缓慢蜿蜒且不自交。真实 path 弧长映射月份；区间截取真实子路径。2–5px/月为初始比例；密集区域聚合、不改变事实日期。漂流湾不分配虚假日期。流动仅表达时间方向，reduced-motion 关闭动画但不改变位置。

## 自传边界变更（替代 ADR0017 第5项的后续方向）

旧 Renderer 限制 keySentence 逐字复制，导致一条记录一段、元数据进入散文。新流水线为固定 manifest → FactAtoms → Narrative Planner → Writer → 独立事实审校 → 最多一次语义修复。事实约束、语言自由；每段可支持多个事实，出处由软件追溯。未知年份不自动生成“年份不详”。家人证言自然归属、争议细节可省略。Persona 只进入 Writer 的语言风格槽。

独立审校是有界模型判断，不是事实真实性证明；确定性检查仍拒绝未知 fact ID、空支持、缺来源及越界输出。审校失败保留前一个已发布自传，不能回退成未经验证的流畅文本。历史 generation 保持旧结构可读，新结果标记 narrative-v2。

## 必须关闭的验收

纯文字原生提交→无媒体 Source→Transcript→抽取→节点→长河；刷新/重启/同档案新采访可见。两档案互不泄漏；旧 singleton 默认档案迁移重启幂等。至少两轮真实截图评审；真实模型自传需连贯自然而非句子拼接。未执行不得声明通过，不提前打 v0.2 tag。

### 尚未通过的叙事门禁

含家人代述、未知时间、开放/已解决冲突的稀疏合成档案，数次真实生成被审校拒绝。曾发现家人归属被模型审校漏检，现有确定性归属检查阻止此类发布；不能把所有失败归咎于格式。最新复测仍为NARRATIVE_UNSUPPORTED，未发布候选正文，旧有效版本保持可读。更完整语料的成功不能替代该复杂场景。需要继续改善计划/写作对稀疏证言的组织，保持事实验证而非退回逐字拼接。**因此不打v0.2标签、不声明RC验收通过。**
