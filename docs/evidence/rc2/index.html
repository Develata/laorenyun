村里的日子

我1952年出生在安徽一个村子。家里有四个孩子，我排行第二；邻居们彼此熟悉，吃过饭就在门口聊天。小时候我常到村边的河里摸小鱼。孩子讲过，家里过去用煤油灯照明。

修理铺

1983年，我在村里开了修理铺；学会修自行车，大概是在开修理铺以前。
