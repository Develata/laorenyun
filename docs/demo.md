## 逐分钟讲稿（7分10秒）

| 时间 | 操作 | 中文讲述 |
|---|---|---|
| 0:00–0:35 | 打开讲故事 | 老人的经历常散落在一次次聊天里。老人云把讲述保存下来，让人能回看、纠正，再慢慢成书。今天的人物和资料全部是合成演示。 |
| 0:35–1:50 | 新采访，短语音或文字，编辑后发送 | 我先补充一句：“1996年，我把修自行车的工具交给了儿子。”这里是真实调用；请看保存反馈和 AI 追问。聊天记录不是最终数据，证言和来源才是原始依据。 |
| 1:50–3:10 | 长河、年代、展开学校树、漂流湾 | 长期记忆组织成记忆图。人生长河是它沿时间的投影；树枝是故事的展开，不是另一条时间轴。没有年月的故事留在漂流湾，不编造日期。 |
| 3:10–4:00 | 详情、来源、更正入口后取消 | 这段工作年份从1982更正为1983。旧证言仍在历史里，但支持当前说法的是更正后的依据。系统不会把旧话擦掉。 |
| 4:00–5:20 | 自传与展开表达方式 | 这里是预置作品，避免课堂等待。表达方式只影响怎么说，不增加发生过什么。自传是依据材料生成的阅读结果，原始证言才是依据。 |
| 5:20–6:00 | 导出，打开离线HTML | 文字、离线网页和完整JSON分别方便阅读和查档。这不是可完整恢复的备份，目前没有导入恢复。 |
| 6:00–6:45 | 架构说明 | 界面和会话由 DSH 承载，业务由插件负责。本地 SQLite 保存领域记录，配置的云服务只处理任务需要的内容。不是全离线 AI。 |
| 6:45–7:10 | 收尾 | AI 整理不等于历史核验。实体麦克风和真人恢复仍有独立验收清单，今天不把合成演示算成人工验收。 |

## A/B/C 三级回退

- **A 完整实时**：真实麦克风→Tencent→编辑→提交→模型追问/抽取。只报告真正完成的步骤。
- **B 文字实时**：语音失败时说“语音服务暂时不可用，我改用文字；后面还是同一条记忆整理流程。”不重复等待超过20秒。
- **C 预置离线**：模型或网络失败时说“现场云服务不可用，下面展示提前准备、明确标记的合成材料。”继续长河、来源/更正历史、表达方式、自传和导出。原始讲述在记忆出处中可见，不伪造已经发生的 DSH 对话。

本机故障按[45秒公网切换](demo-public.md)操作。公网也不可达则使用已下载HTML，从自传和出处继续；不声称云调用成功。
