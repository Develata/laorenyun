# ADR 0018：人物档案隔离与叙事生成

状态：接受（v0.2 实现中，验收见 [重建设计](../v0.2-redesign.md)）。上游保持 0d1f500，v0.1 标签不变。

## 人物档案

一个 DSH Workspace 对应一个人物档案；一个 Session 对应一次采访。使用公开 Workspace 注册表及成员关系，不新增独立工作区身份系统。支线通过持久 parentSession 继承父档案，最大深度一。

每个档案一个 SQLite 文件及媒体/导出根目录；同一进程仍只有一个 SQLite worker，串行处理有界信箱。每次请求携带内部固定 store 路径，浏览器不能提交文件路径。上限 32 个档案。全局内部模型并发上限沿用两路，最多32个等待位置；入队计入60秒调用截止，取消移除等待者。

选择独立 store 是为了复用已有图、出处、支线和派生操作的事务边界，避免为每张历史表补 scope 字段而遗漏查询。代价是 worker 管理最多 32 个连接；不是 32 个线程。所有后台任务在创建时绑定档案；不能跟随浏览器后续切换。

旧 singleton 数据原地保留，原根目录归默认人物档案。`archive-default.json` 使用文件同步及原子 rename 固定映射。迁移只将 cwd 与默认 Workspace 一致的原生 Session 附加到该档案，重复附加幂等；不复制/删除旧库。其它档案使用受控目录和原生 UUID。

## 自传

本条替代 ADR 0017 中逐字 keySentence 渲染约束，旧 generation 不重写。新 generation 标记 `narrative-v2`：固定图 manifest → FactAtoms → 叙事计划 → Writer → 独立审校 → 最多一次语义修复。

FactAtom 保留节点修订、证言、说话者、时间与出处。未知时间为 null；不强制插入时间元数据。段落可以合并事实并自由改写。Writer 同时负责章名与正文，使审校提出的章名问题也可修复。Persona 仅提供风格观察，不把例句中的人生事实带入事实宇宙。

确定性代码验证引用、来源、大小及结构；独立模型审校全文陈述、隐含因果、时间与家人归属。审校报告有界持久化，仅供内部检查。模型审校不是数学证明或历史真实性核验。失败不发布、不覆盖旧版本，不回退为未经审校的拼接或散文。

## DSH 界面

使用品牌、侧栏、主面板、右侧栏、locale 与 settings 公共接口。模型配置、凭据和默认模型仍由 DSH 持有；腾讯设置使用 DSH secret 字段。恢复配置界面不扩大采访工具权限。长河、详情和自传分层，图仍是领域权威。
